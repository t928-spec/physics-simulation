# 縱波觀察點紅色位移範圍：設計規格

## 目標

在既有縱波模擬的黃色觀察點旁加入紅色最大位移範圍，讓學生看出粒子實際振動永遠落在平衡位置兩側的固定振幅內。

## 呈現與行為

- 粒子區：以青色觀察線為中心，畫出從 `−A` 至 `+A` 的紅色水平範圍線及兩端垂直端點；黃色十字會在這個範圍內左右振動。
- 位移圖：以位移平衡線為中心，畫出從 `−A` 至 `+A` 的紅色垂直範圍線及上下水平端點；黃色十字會沿青綠色曲線在此範圍內上下振動。
- 壓力圖不加入紅色範圍，因為此標示專指粒子位移振幅。
- 紅色範圍與黃色十字、青色觀察線同屬「位移線」圖層；關閉該圖層時三者均不繪製。

## 架構與驗證

僅修改 `longitudinal-wave-displacement-pressure.js` 的 Canvas 繪製流程。以 `DEFAULT_WAVE.amplitude` 作為上方水平範圍半寬，並乘上既有 graph scale 作為位移圖垂直範圍半高；不改變物理模型、狀態、控制項或 HTML 結構。

擴充既有頁面契約測試，要求 renderer 包含專責的紅色位移範圍繪製函式；再執行完整 Node 測試與公開 GitHub Pages 視覺檢查。
