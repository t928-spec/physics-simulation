# 分子自由度運動拆解模擬：設計稿

## 目標

建立一個可直接在瀏覽器開啟的繁體中文互動模擬，面向準備物理奧林匹亞的學生。模擬須把分子的平移、轉動、振動拆開顯示，讓學生以「可以獨立指定的運動狀態」理解自由度計數，而非只背誦公式。

本模擬以使用者提供的教材截圖為內容依據：

- 單原子理想氣體：3 個平移自由度。
- 雙原子分子：常溫剛性轉子近似下為 3 平移 + 2 轉動 = 5；啟用振動後為 7。
- 線型三原子分子：用作多原子分子的進階比較對象；清楚區分線型分子的平移、非繞鍵軸轉動與正規振動。

## 非目標

- 不建立完整的分子動力學、碰撞或統計力學熱平衡模型。
- 不在第一版加入溫度滑桿、能量均分的數值計算、測驗或作答紀錄。
- 不把線型三原子分子的所有振動模態簡化成「只要多原子就有固定 f」；畫面必須標示使用的近似與狀態。

## 互動與畫面架構

新增獨立頁面 `molecular-degrees-of-freedom.html`，並從首頁加入入口卡片。頁面採桌面投影與一般手機瀏覽器皆可使用的響應式雙欄版面。

### 頂端控制

- 分子選單：單原子、雙原子、線型三原子。
- 三個情境快捷鍵：僅平移、剛性分子、加入振動。
- 播放／暫停與重設按鈕。

快捷鍵改變的是已啟用的模式集合：

| 情境 | 單原子 | 雙原子 | 線型三原子 |
| --- | --- | --- | --- |
| 僅平移 | 3 平移 | 3 平移 | 3 平移 |
| 剛性分子 | 3 平移 | 3 平移 + 2 轉動 | 3 平移 + 2 轉動 |
| 加入振動 | 不適用 | 3 平移 + 2 轉動 + 1 伸縮振動 | 顯示已選的正規振動模式，並將其計入目前可觀察的獨立模式 |

### 動畫畫布

- 深色、有細緻座標網格的畫布，包含可辨識的 x、y、z 軸與固定的畫面中心。
- 原子以顏色與大小區分；鍵結使用可伸縮的彈簧或鍵線。
- 畫布中的分子位置、方向與內部鍵長／夾角，由各啟用模式的明確週期函數疊加產生；不是隨機走動。
- 每個啟用模式對應一個顏色標記與動態向量／環形箭頭，使平移、轉動、振動的來源可追蹤。

### 模式控制面板

依分子類型顯示可勾選的獨立模式：

- 單原子：沿 x、y、z 平移。
- 雙原子：沿 x、y、z 平移；繞垂直鍵軸的兩個轉動；鍵長伸縮振動。
- 線型三原子：沿 x、y、z 平移；繞兩個垂直分子軸的轉動；對稱伸縮、非對稱伸縮與彎曲振動。彎曲振動將明確標示為退化模態（兩個獨立方向），避免誤導為只有一個振動自由度。

每一列包含模式名稱、符號或軸向、開關，以及一段短的物理意義。啟用／停用後動畫和計數立即更新。

### 即時讀值與解釋卡

- 顯示目前啟用的「可見模式數」與分項算式，例如 `f = 3（平移）+ 2（轉動）+ 1（振動）= 6`。
- 同時顯示「教材中的熱容量計數」；對雙原子在振動情境下，將明確分開「振動正規模態數」與「能量二次項對 f 的貢獻」，使畫面可與截圖的 `f=7` 一致：一個伸縮振動模式包含動能與位能兩個二次項。
- 顯示所用近似（剛性轉子、線型分子）；解釋繞鍵軸轉動因轉動慣量很小，在此近似下不計入。
- 點選任一模式，可在解釋卡以醒目文字說明它為何可獨立指定、為何算作一個自由度或一個振動模式。

## 物理規則與資料模型

每個分子定義一組模式資料，包含 `id`、分類（translation/rotation/vibration）、名稱、可見計數、熱容量貢獻、動畫參數與說明。介面從這些資料產生，避免控制項、動畫與 f 計數各自硬編碼而失去一致性。

`f` 顯示採兩種明確標籤：

1. **機械座標／正規模態數**：用於回答「有幾種可獨立運動？」。
2. **能量均分定理的二次項數**：用於對應截圖中的內能公式 `U = (f/2)nRT`。

對雙原子：3 平移 + 2 轉動 = 5；加入一個伸縮正規模態時，機械模式增加 1，但均分定理的 f 增加 2，因此為 7。此區分是此模擬的核心教學防錯機制。

對線型三原子：預設只開啟平移與剛體轉動。選取任一振動模式後，卡片顯示該模式的機械模態與相應的能量二次項；退化彎曲模態會清楚標成兩個獨立方向。第一版不宣稱所有振動都在一般溫度下完全激發。

## 動畫計算

每一動畫影格先計算中心質量的三分量位移，再計算方向向量的兩個小角度旋轉，最後疊加振動位移。分子座標由此生成，並投影成畫布的 2D 位置。振動以固定且互不相同的角頻率顯示，避免所有運動同步造成學生誤以為它們不是獨立模式。

使用 `requestAnimationFrame`；視窗失焦或按暫停時停止更新。重設會回到該分子的預設情境與相位零點。使用者不需安裝套件，也不需連網。

## 可近用性與錯誤處理

- 所有開關與按鈕皆使用原生可聚焦控制項，並有中文文字標籤。
- 動畫畫布提供簡短文字替代說明，讀值不只依賴顏色。
- 窄螢幕時，畫布、模式面板與解釋卡垂直堆疊。
- 若使用者選了不適用的快捷情境（如單原子的「加入振動」），系統維持平移模式，並顯示理由而非產生無效動畫。

## 驗收條件

1. 首頁可進入新頁面；新頁面可離線直接開啟。
2. 單原子可個別切換三個平移分量，並顯示 `f = 3`。
3. 雙原子在剛性情境下顯示 3 平移 + 2 轉動 = 5，且兩個轉動在畫面上可辨識。
4. 開啟雙原子伸縮振動後，畫面顯示鍵長週期改變，並明確說明為何能量均分定理的計數從 5 變為 7。
5. 線型三原子提供可見的平移、轉動、對稱伸縮、非對稱伸縮與雙重退化彎曲振動；不把繞分子軸轉動列為剛體自由度。
6. 勾選任一模式後，動畫、模式清單、目前計數與文字解釋在同次介面更新中保持一致。
7. 桌面與窄螢幕下均可使用；沒有 JavaScript 主控台錯誤。
