# 理想閉管模型與實測單簧管對照設計

## 目的

讓學生先在匿名樣本 A 看見清楚的閉管奇次諧波模型，再以原本單簧管 D5 的真實頻譜比較理想模型與樂器實測的差異。所有揭曉處加入一致的樂器／模型教學插圖。

## 聲音與活動流程

- 樣本 A 改為瀏覽器內建的理想一端閉管模型聲，基音設定為 300 Hz，僅疊加 300、900、1500 Hz，讓三個奇次分量都落在既有 0–1800 Hz 圖中。
- A 的揭曉明示為「理想一端閉管模型聲」，不是實際樂器；說明它用於對照理想駐波頻率 f、3f、5f。
- B 維持直笛實錄，C 維持古典吉他實錄。
- 三張匿名卡之後新增「實測對照：原本的單簧管 D5」；顯示名稱、圖片、播放器與即時頻譜，並指出其 2f 成分可很強，不能直接當成理想閉管的證據。
- 原本單簧管 WAV 仍保留且在對照區使用；授權資訊維持可追溯。

## 圖片

- A 使用一端封閉、一端開放的管柱教學插圖。
- B 使用直笛插圖，C 使用古典吉他插圖，實測對照使用單簧管插圖。
- 圖片是無文字、透明背景、同一柔和教育插畫風格；只在對應答案或已揭曉的對照區出現。

## 技術與檢查

- 以 Web Audio API 產生模型聲並接入相同的 AnalyserNode，讓 A 的即時頻譜可被既有鎖定平均功能讀取。
- 所有音源在使用者按播放後才建立或恢復 AudioContext。
- 測試 A 的模型字樣、奇次頻率設定、實測單簧管對照區、四個圖片資產和盲聽區未提前洩漏身分。
