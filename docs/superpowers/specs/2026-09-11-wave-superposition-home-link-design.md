# 波的疊加模擬：首頁入口設計稿

## 目標

將新增的 `wave superposition.html` 納入物理互動實驗室首頁，讓學生能從首頁開啟「三角脈衝波疊加與質點振動速度」模擬。

## 範圍

- 在 `index.html` 的模擬卡片網格新增一張卡片，連結至 `./wave superposition.html`。
- 卡片沿用現有首頁的卡片結構與互動樣式；以 CSS 繪製波動預覽，不新增影像檔案。
- 卡片標籤為「波動」與「疊加原理」，標題為「三角脈衝波疊加與質點振動速度」。
- 說明文字聚焦兩個相向三角脈衝的疊加，以及固定位置質點的振動與速度。
- 首頁前言與主題統計從 5 個更新為 6 個；主題分類保留電學、波動、軌道力學與熱學。

## 非目標

- 不修改 `wave superposition.html` 的內容、檔名或互動行為。
- 不變更其他模擬卡片與首頁的版面配置。

## 驗收

- 首頁可顯示第六張模擬卡片，並維持桌面與窄螢幕的既有響應式排列。
- 點擊新卡片能開啟 `wave superposition.html`。
- 首頁顯示的模擬數量與實際卡片數一致，且新卡片的文字清楚描述功能。
