# 直笛素材與傅立葉延伸設計

## 目的

維持三個樣本皆為 D5（約 587 Hz）的公平比較，將辨識度不足的直笛音色替換為更自然的 CC0 錄音；在所有樣本的揭曉後補上可銜接頻譜活動的傅立葉轉換原理與應用。

## 音檔

- 僅替換樣本 B；樣本 A 單簧管與樣本 C 吉他的 D5 保持不變。
- 新樣本必須是可合法隨網站散布、明確為 D5 的直笛長音。
- 選用 Freesound 的 `Alto Recorder D5`（sgossner，CC0），其近距離錄製與顫音預期較容易被辨識為直笛。
- 更新 `CREDITS.md` 的演奏者、來源連結與原始檔名；不在盲聽區提前顯示樂器名稱。

## 最後延伸區

新增在「最後再比一比」之後，所有音色、模型與時間線索均已揭曉時才閱讀。

1. **直觀說明：** 複雜波形可由不同頻率的正弦／餘弦波相加表示；頻譜將問題由「振幅對時間」改為「強度對頻率」。
2. **數學理由：** 以週期函數的傅立葉級數、正交關係與投影公式說明不同頻率的項如何被分離；公式使用可讀的區塊格式。
3. **數位實作：** 以有限取樣的 DFT 公式說明 FFT 是快速計算法，並以「有限時間窗會限制頻率解析度」連結目前的平均頻譜操作。
4. **應用：** 手機調音器、等化器／音色辨識，以及 MRI 的影像重建；避免將 MRI 誤稱為聲音分析。

## 檢查

- 測試三段音檔仍存在、B 的授權標示為 CC0 並保留 D5 資訊。
- 測試延伸區出現在揭曉後，含正交關係、傅立葉級數、DFT／FFT、三個應用與波形—頻譜的對照。
- 完整測試仍通過。
