# 縱波的位移與壓力：設計規格

## 目標

新增獨立的「縱波的位移與壓力」HTML 模擬頁面，將提供的 Flash 動畫完整重建為可直接部署至 GitHub Pages 的瀏覽器互動教材。新頁面沿用現有 Physics Lab 網站的視覺系統，而非沿用舊動畫的深藍版面。

本模擬協助學生同步觀察空氣粒子的來回振動、縱波的密疏、粒子位移與壓力變化，並理解位移與壓力相差四分之一波長。

## 範圍與非目標

本版保留原動畫已辨識的操作：播放快慢、播放／暫停、重來、可拖曳觀察游標，以及波形、位移、壓力、位移線和輔助線的各別顯示開關。說明按鈕改為網頁內的教學說明視窗。

它是理想的一維正弦行進縱波模型，不加入聲音播放、反射邊界、吸收、非線性效應、帳號或資料儲存。

## 介面與操作

頁面使用既有網站的淺色卡片、標題與控制元件風格：主區為一個大型 Canvas，右側或下方為控制卡；窄螢幕時依序顯示模擬、控制與說明。

Canvas 由三個同步區域構成：

- 上方粒子區：以白色粒子表示空氣微粒，並以垂直線條／彈簧的疏密表示縱波。壓縮處粒子較密，稀疏處粒子較疏。
- 中段位移圖：青綠色曲線畫出各平衡位置的水平位移；中心線標示右、位移、左。
- 下段壓力圖：黃色曲線畫出相對於平衡壓力 `P₀` 的壓力變化；中心線標示 `+ΔP`、`P₀`、`−ΔP`。

可拖曳的垂直觀察游標貫穿三個區域。它選定一個粒子的平衡位置；黃色正字記號會隨該粒子在粒子區左右振動，並在兩張圖上標記該位置當下的位移與壓力。游標拖到新位置時，三處讀值與標記立即切換至新的粒子。

控制項如下：

- 播放快慢滑桿：調整動畫相位推進速度。
- 播放／暫停按鈕：停止或恢復動畫，並清楚反映目前狀態。
- 重來按鈕：回到初始相位、預設速度與預設觀察位置。
- 波形、位移、壓力開關：各別顯示或隱藏上方波形、中段曲線、下段曲線。
- 位移線開關：顯示或隱藏觀察游標與黃色正字記號的同步讀值標示。
- 輔助線開關：顯示或隱藏「密／疏」虛線及其對應的垂直導引線。
- 說明按鈕：開啟教學視窗，說明位移、密疏與壓力的關係。

## 物理模型與視覺呈現

對平衡位置為 `x` 的粒子，位移採用：

`s(x, t) = A sin(kx − ωt + φ)`。

粒子在動畫中的實際水平位置為 `x + s(x, t)`。相對壓力變化使用位移空間梯度：

`ΔP(x, t) = −C ∂s/∂x = −CAk cos(kx − ωt + φ)`。

因此壓力波與位移波相差 `π/2`；最大壓縮（高壓）與最大稀疏（低壓）分別對應位移曲線的過零位置。密／疏標示會從同一物理模型尋找壓力極值，確保粒子、彈簧、圖線與輔助線完全同步。

## 架構

- `longitudinal-wave-physics.js`：無 DOM 的純函式，負責參數正規化、位移、壓力、粒子位置、密疏位置與觀察點讀值。
- `longitudinal-wave-displacement-pressure.html`：頁面結構、樣式、控制與 Canvas 動畫迴圈。
- `tests/longitudinal-wave-physics.test.mjs`：以 Node 內建測試工具驗證物理關係與觀察點讀值。
- `index.html`：新增首頁模擬卡片與連結。

不使用外部函式庫；頁面可離線開啟並可直接部署至 GitHub Pages。

## 錯誤處理與可近用性

動畫速度與游標位置均有安全範圍；非有限數值一律回復安全預設。每個控制項具有清楚標籤與鍵盤可操作性；Canvas 提供對應的文字描述。若 Canvas 尺寸在重新排版時變動，游標位置會按比例保留，而不會跳出顯示範圍。

## 驗證策略

先以測試驅動方式驗證：

1. 位移為零的點，壓力絕對值應為最大值。
2. 位移絕對值為最大值的點，壓力應為零。
3. 粒子實際位置應為平衡位置加上位移。
4. 觀察點讀值與相同位置的位移、壓力函式一致。
5. 非有限輸入與游標越界值會正規化為安全範圍。

完成後，會在瀏覽器實際測試拖曳游標、黃色標記的振動、所有顯示開關、速度、播放／暫停、重來、說明視窗、首頁連結及窄螢幕版面。
