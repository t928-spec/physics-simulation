# 水波干涉：波源至觀察點 P 的路徑波形設計

## 目標

當使用者勾選「顯示到達觀察點 P 的波」時，在干涉場上把原本的兩條虛線路徑升級為可辨識的正弦波。每條波自對應波源延伸至 P，讓學生直接比較兩段路程及抵達 P 時的相位。

## 呈現方式

- S1 到 P 以藍色波形表示，S2 到 P 以紅色波形表示。
- 每條波形沿其直線路徑的法線方向上下振動；淡色虛線仍作為路徑中心線。
- 波形只在開關啟用時繪製；關閉時維持原本乾淨的干涉場。
- 波源、P 點、程差提示與下方兩列到達波形繼續保留。
- 在波形後方加窄的半透明深色帶，提高黃色干涉場上的辨識度。

## 物理對應

對從波源出發、已走過距離 s 的波，繪圖相位使用：

`phase(s, t) = 2πs / λ − ωt + φsource`

其中波源 1 的 `φsource = 0`，波源 2 的 `φsource = θ`。路徑終點 `s = r1` 或 `s = r2` 時，這個相位必須分別等於物理模組回傳的 `wavePhase1` 或 `wavePhase2`。因此圖上波形、干涉場與程差讀值共用同一相位定義。

## 架構與驗證

只修改 `water-wave-interference.html` 的疊圖繪製，物理計算模組不增加重複公式。新增頁面結構測試，確認路徑波形函式同時使用波源至 P 的距離、波長、時間與觀測相位。既有物理測試與首頁測試必須維持通過。

## 範圍

本次不改變水波干涉場的色彩、控制項、程差公式或下方到達 P 的雙波形圖。
