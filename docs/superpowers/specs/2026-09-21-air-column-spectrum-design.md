# 空氣柱與弦振動：聲音偵探頁面設計

## 目的

在 GitHub Pages 上提供一個可課堂投影或學生個別操作的活動頁。學生從三段未標示樂器的聲音出發，使用播放中的即時頻譜來推論振動系統，最後才揭露樂器與近似物理模型。

## 探究流程

1. **盲聽**：以樣本 A、B、C 呈現；只提供播放控制與記錄猜想的位置，不顯示樂器、發聲分類或答案。
2. **頻譜判讀**：學生播放任一樣本時，頁面即時顯示 FFT 頻譜與主要峰值。引導其找出最可能的基音，並觀察峰值是否接近整數倍或以奇次倍數為主。
3. **模型配對**：顯示三張匿名的理想諧波規律卡，分別表示全整數倍、奇次倍與近似整數倍但有微小偏移的關係。學生將樣本與模型配對；此時仍不揭露模型名稱。
4. **揭曉與解釋**：顯示各樣本的實際樂器、近似模型（兩端開放空氣柱、一端閉一端開空氣柱、兩端固定弦），及真實系統與理想模型不同的原因。
5. **延伸觀察**：最後才可展開時域振幅包絡圖與「能量如何持續輸入」討論。這是加深觀察，不是判讀諧波的必要步驟；並指出拉弓弦等反例，避免把演奏方式誤當成樂器家族的固定特徵。

## 介面與資料

- 新增 `air-column-spectrum.html`，沿用既有靜態頁面與繁體中文視覺風格。
- 首頁加入一張活動卡，連往新頁面。
- 音檔存放於專案內的 `assets/air-column-spectrum/`，讓本機開啟與 GitHub Pages 都可播放。
- 每段音檔在使用者按下播放後，透過 Web Audio API 的 `AnalyserNode` 讀取資料；以 Canvas 繪製即時頻譜，並用峰值偵測提供讀圖輔助。播放必須由使用者觸發，以符合瀏覽器音訊政策。
- 音檔使用可再利用的 CC0 樣本，頁面底部提供來源、錄音者與授權連結。

## 教學邊界與錯誤處理

- 不把「最高峰」直接宣告為基音；引導學生用峰值間距與倍頻規律驗證基音。
- 明確標示單簧管、直笛與吉他都只是近似對應理想模型；按孔、吹口、喇叭口、共鳴箱與弦剛性皆可改變頻譜。
- 音訊分析不可用時，播放器、分段揭露與文字引導仍可使用，並顯示簡短提示。
- 手機與平板螢幕以單欄卡片、可捲動頻譜為優先。

## 驗證方式

- 三段音檔可在 GitHub Pages 與直接開啟 HTML 時播放。
- 每段樣本可各自完成五階段揭露，且初始畫面不含樂器與模型名稱。
- 播放時頻譜會持續更新，暫停後畫面保留最後一次頻譜。
- 以桌面與窄螢幕檢查按鈕、圖表與揭曉內容可操作、可閱讀。
