# 雙繩交界繩波模擬：設計稿

## 目標

製作一個可直接由瀏覽器開啟的高中物理互動模擬頁面，讓學生觀察同張力、不同線密度的兩段繩子交界時，入射波、反射波與透射波的行為與能量分配。

## 使用情境與範圍

- 可各自調整左、右繩的線密度；兩端張力固定且相同。
- 可選擇單一脈波或連續週期波，以及正弦波或三角波形。
- 提供振幅與時間尺度控制：脈波使用寬度，連續波使用頻率。
- 提供播放、暫停、重設、慢動作，以及「輕繩傳重繩」「重繩傳輕繩」「相同繩」預設情境。
- 不模擬阻尼或能量耗散；顯示的能量比例必須守恆。
- 提供獨立的「公式推導」教學頁，從模擬頁與實驗室首頁可開啟；頁面可使用模擬帶入的線密度顯示對應數值例子。

## 物理模型

張力在接點兩側為同一常數 `T`，因此每段繩的波速為：

`v = sqrt(T / μ)`

其中 `μ` 是該段繩的線密度。以左繩為入射側、波向右傳播為預設，交界處的位移振幅係數採：

`r = (v2 - v1) / (v1 + v2)`

`t = 2 v2 / (v1 + v2)`

其中 `r = Ar / Ai`、`t = At / Ai`；`v1` 與 `v2` 分別為左、右繩波速。能量比例採平均功率比：

`R = r²`

`τ = (μ2 v2 / (μ1 v1)) t² = 1 - R`

顯示時統一標為「反射能量 R」與「透射能量 τ」，並以百分比表示；以計算容忍誤差修正最後一位，使 `R + τ = 100.0%`。反射波的正負號保留：由輕繩進入重繩時反相，由重繩進入輕繩時不反相。

## 畫面與互動

頁面採單頁結構，包含：

1. 標題與一段說明，提示「固定張力、無能量損失」。
2. 左側控制面板：線密度、波型、振幅、寬度／頻率、速度與情境按鈕。
3. 中央大型畫布：兩段不同顏色與紋理的繩子、清楚的交界標記，以及播放中的波形。
4. 模式切換：
   - **數值模擬**：以有限差分法更新離散繩節；接點套用位移連續與張力橫向分量連續的條件。
   - **概念拆解**：使用相同物理係數分色繪出入射（藍）、反射（紫）、透射（橘）波，可慢放並讓學生辨認方向與相位。
5. 右側「即時物理讀值」：`v1`、`v2`、振幅反射／透射比、R、τ 與守恆檢核。

小螢幕時控制面板、畫布、讀值卡片改為直向排列；重要按鈕與數值保持可觸控。

## 公式推導頁

公式推導頁為獨立的 `string-wave-derivation.html`，採循序閱讀的教學結構，而非將大量公式塞入模擬畫布：

1. 說明固定張力下 `v = sqrt(T / μ)`，並以目前的 `μ1`、`μ2` 算出 `v1`、`v2`。
2. 用接點兩側的小示意圖說明位移連續 `Ai + Ar = At` 與橫向力連續 `k1(Ai - Ar) = k2 At`。
3. 代入 `k = ω / v`，逐步化簡得到 `r = Ar / Ai = (v2 - v1) / (v1 + v2)` 以及 `t = At / Ai = 2v2 / (v1 + v2)`。
4. 由平均功率比例 `P ∝ μω²A²v` 推得 `R = r²`、`τ = (μ2v2 / μ1v1)t² = 1 - R`，並顯示守恆檢核。
5. 以輕→重、重→輕兩個對照卡片總結：輕→重反射反相，重→輕反射同相。

模擬頁以查詢參數傳遞目前的 `μ1` 與 `μ2` 至推導頁；推導頁驗證參數為正且落在可視範範圍，無效值回復預設的輕→重情境。兩頁均提供清楚的往返連結。

## 資料流與元件邊界

- **控制器**：驗證並正規化使用者的線密度與波形設定，設定改變時同步重設初始波。
- **係數計算器**：只依 `μ1`、`μ2` 與固定 `T` 回傳波速、振幅係數及能量比例；不依賴畫面。
- **數值引擎**：保存離散位移、速度與時間，單一步進後輸出繩形；只處理波動方程與接點條件。
- **概念引擎**：用同一組係數產生三個可視化波形；只處理教學顯示。
- **繪圖與介面**：讀取兩個引擎的輸出，渲染畫布、圖例與讀值，不自行重算物理量。

## 例外與邊界處理

- 線密度限制為正值且限定合理可視範範圍；輸入無效時回復最近一次有效值。
- 同線密度時 `R = 0%`、`τ = 100%`，不應出現可見反射波。
- 超出畫布範圍的波不再顯示，避免從邊界不物理地反彈；重設後重新發出入射波。
- 在數值模式採穩定時間步長（CFL 條件）以避免波形數值爆炸；畫面更新與物理步進解耦。

## 驗收與測試

- 三個預設情境的波速方向正確：較輕繩波速較大。
- 輕→重反射脈波反相，重→輕反射脈波同相。
- 連續正弦波與三角波皆可播放，且調整頻率／寬度能立即重設正確波形。
- 對多組線密度，讀值都滿足 `R + τ = 100.0%`。
- 數值模式的接點行為與概念模式的反射／透射係數一致（允許離散化造成的微小視覺差）。
- 以桌面與窄螢幕瀏覽器檢查，控制項、畫布與讀值皆可操作與閱讀。
- 公式推導頁可依序閱讀五個推導步驟，公式與數值例子和模擬頁讀值一致，且輕→重／重→輕的相位結論正確。

## 非目標

- 不處理不同張力、阻尼、非線性大振幅、有限長繩邊界反射或兩端同時發波。
- 不包含帳號、儲存、後端服務或外部套件需求。
