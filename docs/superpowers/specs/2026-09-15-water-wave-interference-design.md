# 水波雙波源干涉模擬：設計規格

## 目標

新增獨立的「水波干涉：波程差與相位差」HTML 模擬頁面，專門協助學生從兩個點波源、程差與初始相位差理解相長與相消干涉。既有的「雙狹縫干涉：旋轉狹縫與屏幕」頁面維持不變。

首頁新增一張連往新頁面的卡片。

## 範圍與非目標

新模擬以水波點波源為模型，非光學雙狹縫模型。它會重現參考畫面所需的操作概念，但不複製其版面、圖像或程式。

此版本不加入多波源、反射邊界、真實水槽流體模擬或帳號／資料儲存功能。

## 介面與操作

頁面採用現有 Physics Lab 的淺色卡片語言：桌機版左側為控制面板、右側為大幅干涉場；窄螢幕時依序改為干涉場、控制與教學讀值。

控制項如下：

- 播放／暫停：停止或恢復相位隨時間推進。
- 波長 λ：滑桿改變波數與波紋密度。
- 波源距離 d：滑桿改變兩點波源的間距。
- 波源同相與波源反相：互斥選擇，分別將相位差設定為 0° 或 180°。
- 波源相位差 θ：0° 至 360° 的滑桿；手動調整時進入「自訂相位」狀態，不再宣稱同相或反相。
- 顯示到達觀察點 P 的波：開關路徑與兩列到達 P 的波形比較。

使用者可在干涉圖內點擊或拖曳設定觀察點 P。畫面會標示兩點波源和 P，並顯示兩條路徑。

## 物理模型與視覺呈現

第 i 個波源在位置 `(xi, yi)` 產生的位移為：

`yi(r, t) = A sin(2πr / λ − ωt + φi)`。

干涉場使用兩波位移總和 `y = y1 + y2` 進行色彩映射，形成連續流動的亮暗波紋。波源預設同相，且波源間距與波長的比值會即時顯示。

對觀察點 P，顯示：

- `r1`、`r2` 與程差 `Δr = r2 − r1`；
- 歸一化程差 `Δr / λ`；
- 總相位差 `Δφ = 2πΔr / λ + θ`；
- `cos(Δφ)` 對應的相長、部分干涉或相消判讀。

開啟觀察點波形後，輔助區以可辨識的雙色曲線畫出兩列到達 P 的波，並顯示它們的相對位移；此為教學輔助，不改變干涉場計算。

## 架構

- `water-wave-physics.js`：無 DOM 的純函式，負責參數正規化、單點兩波位移、程差、相位差與干涉判讀。
- `water-wave-interference.html`：版面、控制、Canvas 繪圖、動畫時鐘與可拖曳觀察點。
- `tests/water-wave-physics.test.mjs`：以 Node 內建測試工具驗證物理函式。
- `index.html`：新增首頁卡片與模擬總數。

模擬不依賴外部函式庫，離線開啟即可使用。

## 錯誤處理與可近用性

輸入值均受 HTML 範圍限制，物理模組仍會將無效或非有限數值回復為安全預設。Canvas 會提供清楚的替代描述；每個滑桿有顯示數值的標籤，按鈕會反映播放狀態。

## 驗證策略

先以測試驅動方式驗證：

1. 同相且程差為整數倍波長時，總相位差為整數倍 `2π`，判讀為相長。
2. 同相且程差為半整數倍波長時，判讀為相消。
3. 反相且程差為零時，判讀為相消。
4. 手動相位差會正確併入總相位差。
5. 非有限或越界參數會正規化為安全值。

完成後會以瀏覽器實際操作波長、距離、相位、播放及觀察點，並檢查首頁連結與窄螢幕版面。
