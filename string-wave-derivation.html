兩段繩的波速

張力在交界兩側相同，因此線密度較小的繩，波速較大。

v = √(T / μ)
2

交界必須同時滿足兩個條件

接點不能裂開，因此左右位移相同；接點也不能有未平衡的橫向力。

Aᵢ + Aᵣ = Aₜ
k₁(Aᵢ − Aᵣ) = k₂Aₜ

其中 Aᵢ、Aᵣ、Aₜ 分別是入射、反射、透射波的振幅；負號源自反射波的傳播方向相反。

3

求出振幅反射與透射係數

因為入射波、反射波與透射波頻率相同，k = ω / v。將它代入接點的兩個條件：

r = Aᵣ / Aᵢ = (k₁ − k₂) / (k₁ + k₂)= (v₂ − v₁) / (v₁ + v₂)t = Aₜ / Aᵢ = 2v₂ / (v₁ + v₂)
4

由平均功率得到能量比例

繩波的平均功率與 μ、振幅平方及波速成正比。把振幅比代入後，能量自動守恆。

P ∝ μω²A²v
R = Pᵣ / Pᵢ = r²τ = Pₜ / Pᵢ = (μ₂v₂ / μ₁v₁)t² = 1 − RR + τ = 1
5

方向與相位的物理意義

反射係數 r 的正負號，決定反射脈波是否上下顛倒。

輕繩 → 重繩v₂ < v₁，所以 r < 0：反射波反相。
重繩 → 輕繩v₂ > v₁，所以 r > 0：反射波同相。
